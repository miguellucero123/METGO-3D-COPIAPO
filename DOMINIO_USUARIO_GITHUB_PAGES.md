## 🎯 Dominio de Usuario vs. Repositorio

GitHub Pages ofrece dos tipos de sitios:

### 1. Sitio de Repositorio (Lo que tienes ahora)
```
https://miguellucero123.github.io/METGO-3D-COPIAPO/
```
- URL incluye el nombre del repositorio
- Un repositorio = un sitio

### 2. Sitio de Usuario (miguellucero123.github.io)
```
https://miguellucero123.github.io/
```
- URL directa sin nombre de repositorio
- Solo puedes tener UNO
- Requiere un repositorio especial llamado: `miguellucero123.github.io`

## 🚀 Cómo Crear tu Sitio de Usuario (Opcional)

Si quieres que tu sitio esté en `https://miguellucero123.github.io/` (sin el nombre del repo):

### Opción 1: Crear Nuevo Repositorio Especial

1. Ve a GitHub y crea un **nuevo repositorio**
2. **Nombre EXACTO**: `miguellucero123.github.io` (debe ser exactamente tu usuario + .github.io)
3. **Debe ser público**
4. Crea un archivo `index.html` en ese repositorio
5. Activa GitHub Pages (automático para este tipo de repo)
6. Tu sitio estará en: `https://miguellucero123.github.io/`

### Opción 2: Renombrar tu Repositorio Actual

Si quieres usar el repositorio actual como sitio de usuario:

1. Ve a: https://github.com/miguellucero123/METGO-3D-COPIAPO/settings
2. Scroll hasta "Repository name"
3. Cambia el nombre a: `miguellucero123.github.io`
4. Confirma
5. GitHub Pages se actualizará automáticamente
6. Tu sitio estará en: `https://miguellucero123.github.io/`

**⚠️ IMPORTANTE:**
- Solo puedes tener UN sitio de usuario
- Si renombras el repo, la URL antigua dejará de funcionar
- El nuevo repositorio debe llamarse exactamente: `tu-usuario.github.io`
