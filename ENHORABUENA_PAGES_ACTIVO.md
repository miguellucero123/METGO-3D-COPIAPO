## ⚠️ Nota Importante sobre el Mapa

Si el mapa **no se muestra** (se ve vacío), es porque GitHub Pages tiene restricciones de seguridad con iframes.

**Esto NO es un error tuyo**, es una limitación de GitHub Pages.

### Si el mapa no se ve, tienes 2 opciones:

#### Opción 1: Usar Netlify (Funciona Perfecto) ⭐ Recomendado

1. Ve a: https://app.netlify.com
2. Login con GitHub
3. "Add new site" → "Import an existing project"
4. Selecciona: METGO-3D-COPIAPO
5. Deploy

**Ventajas de Netlify:**
- ✅ El mapa funciona al 100%
- ✅ Deploy más rápido
- ✅ HTTPS automático
- ✅ Gratis
- ✅ Funciona con repos privados también

#### Opción 2: El mapa como está

- El sitio web funciona perfectamente
- Solo el iframe del mapa puede no cargar
- Todo lo demás (gráficos, tablas, diseño) funciona
